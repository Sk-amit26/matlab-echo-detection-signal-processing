# Echo Detection Using Signal Processing in MATLAB
This project demonstrates echo detection and signal analysis using MATLAB.
A received signal is generated by combining a main signal with a delayed and attenuated echo along with Gaussian noise. Different signal-processing techniques are then used to analyze the signal.
## Objectives
- Generate a transmitted signal- Generate a main signal- Simulate a delayed echo- Apply echo attenuation- Add Gaussian noise- Analyze signals in the time domain- Analyze signals in the frequency domain- Implement cross-correlation- Implement DFT- Implement autocorrelation
## Signal Parameters
| Parameter | Value ||---|---:|| Sampling frequency | 1000 Hz || Transmitted signal frequency | 50 Hz || Main signal frequency | 120 Hz || Echo delay | 0.2 s || Echo attenuation | 0.7 || Noise power | 0.5 |
## System Model
```textTransmitted Signal        │        ↓      Delay        │        ↓   Attenuation        │        ↓       Echo        │        ├──────────────┐        ↓              │Main Signal ───────→  (+) ──→ Received Signal                       ↑                       │                     Noise
````

## Signal Processing

The project uses three main techniques:

### 1. Cross-Correlation

Cross-correlation is used to identify the location of the transmitted signal within the received signal.

### 2. DFT

A Discrete Fourier Transform is implemented manually using nested loops to analyze the frequency spectrum.

### 3. Autocorrelation

Autocorrelation is applied to the received signal for signal detection and analysis.

## Processing Flow

```
Generate Transmitted Signal          ↓Generate Main Signal          ↓Introduce Echo Delay          ↓Apply Attenuation          ↓Add Gaussian Noise          ↓     Received Signal          ↓ ┌────────┼──────────┐ ↓        ↓          ↓FFT   Cross-Corr  Auto-Corr ↓        ↓          ↓Frequency Signal   SignalAnalysis Detection Detection
```

## Requirements

- MATLAB

No additional toolbox is required for the core implementation.

## How to Run

1. Open `echo_detection.m` in MATLAB.

2. Set the file as the current script.

3. Run the script.

4. The generated plots will show the time-domain and frequency-domain analysis.
