# Echo Detection Using Signal Processing in MATLAB

This project demonstrates echo detection and signal analysis using MATLAB.

A received signal is generated by combining a main signal with a delayed and attenuated echo along with Gaussian noise. Different signal-processing techniques are used to analyze and detect signal characteristics.

## Objectives

- Generate a transmitted signal
- Generate a main signal
- Simulate a delayed echo
- Apply echo attenuation
- Add Gaussian noise
- Analyze signals in the time domain
- Analyze signals in the frequency domain
- Implement cross-correlation
- Implement DFT
- Implement autocorrelation

## Signal Parameters

| Parameter | Value |
|-----------|-------|
| Sampling Frequency | 1000 Hz |
| Transmitted Signal Frequency | 50 Hz |
| Main Signal Frequency | 120 Hz |
| Echo Delay | 0.2 s |
| Echo Attenuation | 0.7 |
| Noise Power | 0.5 |

## System Model

```text
Transmitted Signal
        │
        ↓
      Delay
        │
        ↓
   Attenuation
        │
        ↓
       Echo
        │
        ├──────────────┐
        ↓              │
Main Signal ───────→  (+) ──→ Received Signal
                       ↑
                       │
                     Noise
````

## Signal Processing

### Cross-Correlation

Cross-correlation is used to identify the location of the transmitted signal within the received signal.

### DFT

A Discrete Fourier Transform (DFT) is implemented manually using nested loops to analyze the frequency spectrum.

### Autocorrelation

Autocorrelation is applied to the received signal for signal detection and analysis.

## Processing Flow

```text
Generate Transmitted Signal
          ↓

          ↓
Introduce Echo Delay
          ↓
Apply Attenuation
          ↓
Add Gaussian Noise
          ↓
     Received Signal
          ↓
 ┌────────┼──────────┐
 ↓        ↓          ↓
FFT   Cross-Corr  Auto-Corr
 ↓        ↓          ↓

Analysis Detection Detection
```

## Requirements

## How to Run

1. Open `echo_detection.m` in MATLAB.
2. Set the file as the current script.
3. Run the script.
4. The generated plots will show the time-domain and frequency-domain analysis.
